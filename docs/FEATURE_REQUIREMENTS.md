# 機能要件（Feature Requirements）

[PRD.md](./PRD.md) を実装可能な単位へ分解した仕様。各機能は「前提・振る舞い・完了条件・例外」を満たして初めて完了とする。

## 機能一覧

| ID | 機能 | 優先度 | 状態 |
| --- | --- | --- | --- |
| F-01 | 展示回廊・絞り込み | Must | 一部完了（カテゴリ連携済・年代絞り込み未実装） |
| F-02 | 展示詳細 | Must | Prototype（モーダル） |
| F-03 | 認証 | Must | 完了 |
| F-04 | しんみり | Must | UIのみ |
| F-05 | コメントスレッド | Must | 完了 |
| F-06 | 展示候補の投稿 | Must | UIのみ |
| F-07 | 並び替え | Should | 未実装 |

## F-01: 展示回廊・絞り込み

**概要:** 展示を博物館の回廊として横方向に閲覧する。

- 前提: 公開済み展示が1件以上ある
- 振る舞い: ホイール、トラックパッド、左右キー、画面内ボタンで移動できる。年代・カテゴリで絞り込める
- 完了条件: 条件に一致する公開展示だけが表示され、展示を選択できる
- 例外: 0件なら条件を解除できる空状態を表示する。取得失敗なら再試行を提示する
- ルール: 縦方向へページ全体をスクロールさせない。`prefers-reduced-motion` では強い移動演出を抑える

## F-02: 展示詳細

**概要:** 展示名、説明、画像、カテゴリ、関連年代、共感数、スレッド入口を表示する。

- 前提: 対象の展示が存在する
- 完了条件: 回廊内のモーダルまたはURLから直接開け、再読み込みしても同じ展示を表示できる
- 例外: 存在しない・削除済みの場合は404相当を表示する

## F-03: 認証

**概要:** メールまたはOAuthで登録・ログイン・ログアウトする。

- 完了条件: セッションが安全に維持され、保護操作では未認証ユーザーをログインへ案内する
- 例外: 認証失敗の内部情報を露出せず、再試行可能な文言を表示する
- ルール: 公開展示・コメント・各いいねの閲覧はログイン不要。展示投稿、コメント投稿・削除、しんみり、コメントいいねの付与・解除はログイン必須

## F-04: しんみり

**概要:** 登録ユーザーが展示へ一度だけ静かな共感を付けられる。

- 前提: ログイン済み
- 振る舞い: 付与と解除をトグルでき、件数へ即時反映する
- 完了条件: 再読み込み後も状態が保持される
- 例外: 保存失敗時は表示を元に戻して通知する
- ルール: `(item_id, user_id)` を一意にし、連打で重複させない

## F-05: コメントスレッド

**概要:** 展示にまつわるエピソードを閲覧・投稿する。

**MVP:**

- コメント閲覧
- ログインユーザーのコメント投稿
- 本人のコメント物理削除
- コメントへのいいね付与・解除と件数表示

- 前提: 閲覧は公開展示、投稿・削除・いいね付与はログイン済み
- 完了条件: 新しいコメントが保存され、投稿者と投稿時刻、いいね件数とともに表示される
- 例外: 空白、上限超過、通信失敗では保存しない
- ルール: 前後の空白を除いて1〜500文字。本文中の改行（連続する空行を含む）は保持する。HTML・Markdownは解釈せず、HTTP/HTTPS URLだけを安全にリンク化する。編集履歴は持たない。本人削除は物理削除する。いいねは `(comment_id, user_id)` を一意にする
- ルール: 一覧は新着順。未認証時は一覧とログイン導線を表示し、`/sign-in?next=/?exhibit={exhibit_id}` からモーダルへ復帰できる。投稿中は二重送信を防ぎ、失敗時は入力を保持する
- ルール: 入力中の本文は展示・ユーザーごとに端末へ下書き保存する。オフライン時は送信せず下書きを保持し、復帰後に送信できる

## F-06: 展示候補の投稿

**概要:** 登録ユーザーが展示候補を画像ファイル・説明・年代とともに送る。

- 必須項目: 名前（1〜100文字）、説明（1〜500文字）、カテゴリ（7カテゴリ）、年代（1900年〜現在年）、画像ファイル（JPEG/PNG/WebP、5MB以下）
- 完了条件: 保存と同時に公開され、回廊と詳細から閲覧できる
- 例外: 必須項目、文字数超過、画像形式、画像容量のいずれかが不正なら保存しない
- ルール: 名前（タイトル）は1〜100文字、説明（思い出本文）は1〜500文字とする。前後の空白を除いて検証する
- ルール: 年代は1900年から日本時間の現在年までの範囲で西暦4桁の整数とする
- ルール: カテゴリは `おかし` / `ゲーム` / `たべもの` / `ほん` / `できごと` / `ガジェット` / `インターネット` の7種類に限定する
- ルール: 画像はJPEG、PNG、WebPのいずれか、かつ5MB以下とする。拡張子だけに依存せず、Server ActionでMIMEタイプと容量を検証する
- ルール: 検証済み画像をSupabase Storageへアップロードし、`items.image_url` にはStorage内の公開画像URLを保存する
- ルール: 投稿は即時公開される。投稿者は、自身がアップロードして問題ない画像のみを使用する。公開後の編集はできず、投稿者本人だけが削除できる


## F-07: 並び替え

**概要:** 新着、しんみり順で展示を並び替える。

- 完了条件: 選択中の条件がURLへ反映され、共有・再読み込みで維持される
- ルール: 既定は新着順とする
