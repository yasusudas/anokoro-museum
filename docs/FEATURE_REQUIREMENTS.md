# 機能要件（Feature Requirements）

[PRD.md](./PRD.md) を実装可能な単位へ分解した仕様。各機能は「前提・振る舞い・完了条件・例外」を満たして初めて完了とする。

## 機能一覧

| ID | 機能 | 優先度 | 状態 |
| --- | --- | --- | --- |
| F-01 | 展示回廊・絞り込み | Must | 一部完了（カテゴリ連携済・年代絞り込み未実装） |
| F-02 | 展示詳細 | Must | Prototype（モーダル） |
| F-03 | 認証 | Must | 完了 |
| F-04 | しんみり | Must | UIのみ |
| F-05 | コメントスレッド | Must | 完了 |
| F-06 | 展示候補の投稿 | Must | UIのみ |
| F-07 | 並び替え | Should | 未実装 |
| F-08 | 展示への反応通知 | Must | 完了 |

## F-01: 展示回廊・絞り込み

**概要:** 展示を博物館の回廊として横方向に閲覧する。

- 前提: 公開済み展示が1件以上ある
- 振る舞い: ホイール、トラックパッド、左右キー、画面内ボタンで移動できる。年代・カテゴリで絞り込める
- 完了条件: 条件に一致する公開展示だけが表示され、展示を選択できる
- ルール: 展示回廊は `year` のYYYY部分が小さい順（古い年代から新しい年代）に表示する。同じ年代は元の順序を維持し、年代未設定の展示は末尾に置く
- 例外: 0件なら条件を解除できる空状態を表示する。取得失敗なら再試行を提示する
- ルール: 縦方向へページ全体をスクロールさせない。`prefers-reduced-motion` では強い移動演出を抑える

## F-02: 展示詳細

**概要:** 展示名、説明、画像、カテゴリ、関連年代、共感数、スレッド入口を表示する。

- 前提: 対象の展示が存在する
- 完了条件: 回廊内のモーダルまたはURLから直接開け、再読み込みしても同じ展示を表示できる
- 例外: 存在しない・削除済みの場合は404相当を表示する

## F-03: 認証

**概要:** メールアドレスまたはGoogleアカウントで登録・ログイン・ログアウトする。

- 完了条件: セッションが安全に維持され、保護操作では未認証ユーザーをログインへ案内する
- 例外: 認証失敗の内部情報を露出せず、再試行可能な文言を表示する
- ルール: 匿名ユーザーは1F固定展示のみ閲覧できる。投稿展示、コメント、しんみり状態の閲覧と、展示投稿、コメント投稿・削除、しんみり、コメントいいねの付与・解除はログイン必須
- ルール: OAuthはGoogleのみを提供する。サインイン画面の「Google で続行」から開始し、`GET /auth/callback` でセッションへ交換する（契約は `API_DESIGN.md` の6章）
- ルール: 利用者がGoogleの同意画面で中断した場合はエラーとして扱わず、サインイン画面へ戻すだけにする
- ルール: ログイン後の復帰先は `next` クエリを同一オリジンの相対パスとして検証した場合だけ採用し、それ以外は `/` へ戻す
- ルール: 1Fヘッダーのログイン導線からログインした場合は、認証後に `/floor/1` へ戻る
- ルール: 未認証の1Fで2F〜6FまたはB1Fを選んだ場合は、ログイン後に選択していたフロアを表示する
- ルール: ログアウト操作を開始した時点で館内BGMを停止する
- ルール: 表示名は登録時のフォーム入力（`user_name` / `display_name`）を優先し、Googleログインでは提供される `full_name` / `name` を採用する。いずれも無い場合だけランダムな既定名を割り当てる

## F-04: しんみり

**概要:** 登録ユーザーが展示へ一度だけ静かな共感を付けられる。

- 前提: ログイン済み
- 振る舞い: 付与と解除をトグルでき、件数へ即時反映する
- 完了条件: 再読み込み後も状態が保持される
- 例外: 保存失敗時は表示を元に戻して通知する
- ルール: `(item_id, user_id)` を一意にし、連打で重複させない

## F-05: コメントスレッド

**概要:** 展示にまつわるエピソードを閲覧・投稿する。

**MVP:**

- コメント閲覧
- ログインユーザーのコメント投稿
- 本人のコメント物理削除
- コメントへのいいね付与・解除と件数表示

- 前提: コメントの閲覧・投稿・削除・いいね付与はログイン済み
- 完了条件: 新しいコメントが保存され、投稿者と投稿時刻、いいね件数とともに表示される
- 例外: 空白、上限超過、通信失敗では保存しない
- ルール: 前後の空白を除いて1〜500文字。本文中の改行（連続する空行を含む）は保持する。HTML・Markdownは解釈せず、HTTP/HTTPS URLだけを安全にリンク化する。編集履歴は持たない。本人削除は物理削除する。いいねは `(comment_id, user_id)` を一意にする
- ルール: 一覧は新着順。未認証時はログイン導線を表示し、`/sign-in?next=/floor/2?exhibit={exhibit_id}` からモーダルへ復帰できる。投稿中は二重送信を防ぎ、失敗時は入力を保持する
- ルール: 入力中の本文は展示・ユーザーごとに端末へ下書き保存する。オフライン時は送信せず下書きを保持し、復帰後に送信できる

## F-06: 展示候補の投稿

**概要:** 登録ユーザーが展示候補を画像ファイル・説明・年代とともに送る。

- 必須項目: 名前（1〜40文字）、説明（1〜500文字）、カテゴリ（8カテゴリ）、年代（1900年〜現在年）、画像ファイル（JPEG/PNG/WebP、5MB以下）
- 完了条件: 保存と同時に公開され、回廊と詳細から閲覧できる
- 例外: 必須項目、文字数超過、画像形式、画像容量のいずれかが不正なら保存しない
- ルール: 名前（タイトル）は1〜40文字、説明（思い出本文）は1〜500文字とする。前後の空白を除いて検証する。既に同じ名前の展示品が存在する場合は保存せず、「その展示品は寄贈されています」とエラーを表示する
- ルール: 年代は1900年から日本時間の現在年までの範囲で西暦4桁の整数とする
- ルール: カテゴリは `食べ物` / `テレビ` / `アニメ` / `ゲーム` / `音楽` / `本` / `出来事` / `その他` の8種類に限定し、アプリ内の共通定義から選択する
- ルール: 画像はJPEG、PNG、WebPのいずれか、かつ5MB以下とする。拡張子だけに依存せず、Server ActionでMIMEタイプと容量を検証する
- ルール: 検証済み画像をSupabase Storageへアップロードし、`items.image_url` にはStorage内の公開画像URLを保存する。投稿時は画像ファイル添付が必須であり、外部画像URLの直接指定は受け付けない
- ルール: 投稿は即時公開される。投稿者は、自身がアップロードして問題ない画像のみを使用する。公開後は編集も削除もできず、利用者が自分で非表示にすることもできない。運営による編集・削除も行わない
- ルール: 未認証で展示作成画面からログインした場合は、認証後に `/exhibits/new` へ戻る


## F-07: 並び替え

**概要:** 新着、しんみり順で展示を並び替える。

- 完了条件: 選択中の条件がURLへ反映され、共有・再読み込みで維持される
- ルール: 既定は新着順とする

## F-08: 展示への反応通知

**概要:** 自分が投稿した展示へのコメントとしんみりを、ヘッダーのベルからまとめて確認する。

- 前提: ログイン済みで、自分が投稿した展示がある
- 振る舞い: 他のユーザーからコメントまたはしんみりが届くとベルに赤い未読印を表示し、ベルを押すと展示名・反応者名・反応種別・日時を新着順のモーダルで表示する。モーダルは画面高さの50％以内に収め、通知一覧が超える場合は一覧部分だけを縦スクロールする
- 完了条件: モーダルを開いた時点で未読通知を一括既読にし、再読み込み後も既読状態を保持する
- 例外: 自分自身によるコメント・しんみり、投稿者のいない固定展示への反応は通知しない。元のコメントまたはしんみりが削除された場合は対応する通知も削除する
- ルール: 通知の閲覧と既読更新は宛先本人だけに許可し、リアルタイム配信やブラウザのプッシュ通知は行わない

## 公開エントランスとフロア導線

- `/` は博物館外観と押せる扉を表示し、未認証でも1Fへ入場できる
- フロアURLは `/floor/[floorId]` に統一し、`floorId` は `b1` または `1`〜`6` のみ受け付ける。不正な値は404を表示する
- `/floor/1` は `supabase/seed.sql` とseedスクリプトで共通管理する固定IDの初期展示による常設展示で、未認証でも一覧と詳細を閲覧できる
- `/floor/2`〜`/floor/6` は利用者が投稿した展示を年代別に表示し、未認証の場合は選択フロアを含むログイン復帰先へ遷移する
- `/floor/b1` はログインユーザーのB1F（自分だけの企画展）を表示し、未認証の場合は `/sign-in?next=/floor/b1` へ遷移する
- 1Fには2Fの価値とログインが必要であることを明示した導線を常時表示する
- ログイン済みユーザーが1Fを含むフロア画面を表示した時だけ、館内BGMとして `Felt and Wood` のループ再生を開始する。未認証の1Fでは再生しない。ブラウザの自動再生制限で開始できない場合は、次の利用者操作を契機に再生する
- フロア間を移動してもBGMの再生位置と選択曲を維持し、ログアウトまたは利用者による停止まで継続して再生する
