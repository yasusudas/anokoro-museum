# PRD（Product Requirements Document）

この文書は「あのころミュージアムで何を、誰のために、なぜ作るか」の正とする。実装単位の詳細は [FEATURE_REQUIREMENTS.md](./FEATURE_REQUIREMENTS.md) を参照する。

## 1. 背景と課題

世代ごとに共有されていた食べ物、番組、音楽、ゲーム、学校行事は、検索すれば情報として見つかっても、偶然出会って誰かと語る体験にはなりにくい。また、世代差は会話の断絶になりやすい一方、「それ知ってる」「自分のころはこうだった」という交流の入口にもなる。

本プロダクトは、懐かしいものをオンラインの展示品として並べ、個人の記憶と世代間の会話を生む。

## 2. プロダクトビジョン

忘れていた「あのころ」に偶然出会い、その記憶を誰かと分かち合えるオンラインミュージアム。

### 提供価値

- 発見: 年代に合う展示から、忘れていた記憶に再会できる
- 没入: 実際の博物館を歩くように、横方向へ展示を巡れる
- 共感: 「しんみり」とエピソードで、言葉にしづらい懐かしさを共有できる
- 交流: 同世代だけでなく、異なる世代の体験も知ることができる

## 3. ゴールと成功指標

MVP公開後に計測基盤を導入し、次を主要指標とする。

| 指標 | 定義 | 初期目標 |
| --- | --- | --- |
| 展示詳細到達率 | 一覧訪問のうち1件以上詳細を開いた割合 | 60%以上 |
| 共感行動率 | 詳細閲覧のうち「しんみり」またはコメントを行った割合 | 20%以上 |
| 回廊探索数 | 1セッションで表示した展示の中央値 | 5件以上 |
| 世代間コメント率 | 展示の中心年代外から投稿されたコメントの割合 | 計測後に設定 |

## 4. ターゲットユーザー

### 主対象

- 2004〜2008年生まれ
- 夏休みなどの休暇中や暇な時間に、懐かしいものへ触れたい人
- PCでゆっくりコンテンツを巡ることに抵抗がない人

### 副対象

- 主対象の家族、友人、先輩・後輩
- 自分の世代の思い出を後世へ残したい人

## 5. ユーザーストーリー

| アクター | したいこと | 価値 |
| --- | --- | --- |
| 来場者 | 生まれ年に合う展示を見たい | 自分に刺さる思い出へすぐ到達できる |
| 来場者 | 回廊を歩くように展示を巡りたい | 一覧検索より偶然性と没入感を得られる |
| 来場者 | 展示にまつわる体験談を読みたい | 他人の記憶から自分の記憶も思い出せる |
| 登録ユーザー | 「しんみり」で共感を表したい | コメントを書かなくても参加できる |
| 登録ユーザー | 思い出や展示候補を投稿したい | 自分の「あのころ」を残せる |

## 6. スコープ

### MVPに含む

- ログイン
- 端末内での生まれ年設定・変更
- 年代とカテゴリによる展示絞り込み
- 横スクロールの展示回廊
- 展示詳細、関連年代、説明
- 展示ごとのコメントスレッド
- コメントへのいいね・件数表示
- しんみりの付与・解除・件数表示
- 登録ユーザーによる展示候補の投稿

### MVPに含まない

- リアルタイムチャット、DM、フォロー
- 動画・音楽ファイルの直接配信
- AIによる投稿生成・自動審査
- ネイティブアプリ
- ランキングを中心にした競争的な体験
- 運営による展示審査・投稿の非公開化・通報対応

## 7. 体験原則

1. 縦のフィードではなく、PC画面内の横移動を基本とする。
2. 暗い館内、壁、床、照明、額縁によって展示空間を感じさせる。
3. 一覧では情報量を抑え、詳細で説明と記憶を開示する。
4. 過度に派手な反応や順位付けより、静かな共感を優先する。
5. 横スクロールが難しい利用者へ矢印キー・ボタンなど代替操作を提供する。

## 8. 制約とリスク

- 投稿画像は必須とし、説明文とともに著作権、商標、肖像権の確認が必要。審査を持たないため確認自体は投稿者の自己申告に依存する
- 政治、災害などセンシティブな出来事は、懐古を強要しない表現が必要。モデレーション機構を持たないため、利用範囲をサークル内に限定する
- 生まれ年はDBへ保存せず端末内に留め、公開プロフィールへ表示しない
- 外部サービスの画像URLへ依存せず、許諾済み素材をSupabase Storageで管理する

## 9. 現在地

2026-08-21時点では、展示回廊、カテゴリ絞り込み、詳細モーダル、しんみり操作をモックデータで実装済み。認証、DB永続化、投稿、コメントは未実装。展示審査は持たない。
