# 要件定義

## プロダクトゴール

2004〜2008年生まれを中心とする来場者が、懐かしい展示をきっかけに自分の記憶を振り返り、世代を越えてエピソードを共有できる場所をつくる。

## 体験原則

1. 一覧ではなく「回廊を歩く」感覚を優先し、PC では横方向に展示を巡る。
2. 暗い館内、壁紙、木の床、照明、額縁で実在する小さな博物館の空気をつくる。
3. 情報量を抑え、展示を開いたときに説明と来場者の記憶が現れる。
4. 「いいね」ではなく、静かな共感を表す「しんみり」を使う。

## MVP

### 来場者

- 生まれ年を設定できる。
- 生まれ年に関連する展示を横スクロールで閲覧できる。
- カテゴリで展示を絞り込める。
- 展示の名前、説明、関連する年代を確認できる。
- 展示ごとのスレッドを閲覧・投稿できる。
- 「しんみり」を付け外しでき、件数を確認できる。

### 登録ユーザー

- メールまたは OAuth でログインできる。
- 展示候補を画像、名前、説明、カテゴリ、年代とともに投稿できる。

## 現在のプロトタイプ範囲

展示回廊、カテゴリ絞り込み、詳細モーダル、しんみり操作をモックデータで実装済み。ログイン、投稿、スレッド、生まれ年の永続化、Supabase 接続は未実装。

## 非機能要件

- 対象: 最新版 Chrome / Edge / Safari の PC 表示。狭い画面でも主要操作は可能にする。
- アクセシビリティ: キーボード操作、フォーカス表示、適切なラベル、十分なコントラストを保つ。
- パフォーマンス: 展示画像は `next/image` と適切なサイズを使い、初期表示に不要な詳細データは遅延取得する。
- セキュリティ: Supabase の Row Level Security を必須とし、公開可否をクライアント入力だけで決定しない。
